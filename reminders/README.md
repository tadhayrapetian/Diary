# Напоминания об уроках

Читает ваш календарь Apple и пишет ученикам в Telegram, что у них скоро урок.
Ничего не нужно отмечать вручную: расписание остаётся там, где вы его и ведёте,
а программа просто смотрит в него и вовремя пишет.

```
Календарь Apple ──CalDAV──► уроки на неделю вперёд ──► кто из учеников чей урок
                                                              │
                        Telegram ◄── «завтра в 15:00» ◄────────┘
```

---

## Что нужно сделать один раз

**1. Завести бота.** В Telegram напишите [@BotFather](https://t.me/BotFather),
команда `/newbot`, придумайте имя. Он ответит токеном вида `12345:AA...` —
скопируйте его в `.env`:

```
TELEGRAM_BOT_TOKEN=12345:AA...
```

**2. Дать доступ к календарю.** Нужен *пароль для программы*, а не обычный
пароль от Apple ID: [appleid.apple.com](https://appleid.apple.com) → «Вход и
безопасность» → «Пароли для приложений» → создать. (Для этого у Apple ID должна
быть включена двухфакторная аутентификация.)

```
APPLE_ID=вы@icloud.com
APPLE_APP_PASSWORD=xxxx-xxxx-xxxx-xxxx
APPLE_CALENDARS=Уроки
```

`APPLE_CALENDARS` можно оставить пустым — тогда читаются все календари.
Посмотреть, какие есть: `node reminders/bot.js calendars`.

**3. Переписать учеников.**

```bash
cp reminders/students.example.json reminders/students.json
```

Внутри — имя, при желании отдельные настройки. Файл перечитывается на каждой
проверке, так что перезапускать программу после правок не нужно.

**4. Разослать ссылки.** Бот не может написать первым — это ограничение
Telegram, а не программы: ученик должен один раз открыть ссылку и нажать
«Начать».

```bash
node reminders/bot.js link          # ссылки для всех, кто ещё не подключён
node reminders/bot.js link Аня      # для одного
```

Отправьте ссылку ученику любым способом. Как только он её откроет, программа
запомнит чат и допишет его в `students.json` сама.

**5. Запустить.**

```bash
npm run reminders
```

Пока команда работает, напоминания уходят. Ниже — как сделать, чтобы она
работала сама.

---

## Что получает ученик

```
Привет, Аня! Напоминаю: урок завтра в 15:00.
```

и за час до урока:

```
Привет, Аня! Напоминаю: урок сегодня в 15:00 (через час).
```

**Название события из календаря по умолчанию не пересылается.** Календарь ваш и
подписи в нём ваши: «Аня — оплатить до среды», «пробный, не забыть учебник» —
такое ученику видеть незачем. Если названия у вас безобидные, включите
`"includeTitle": true` в `students.json`. Можно и наоборот — задать ученику
собственную тему, которая появится в напоминании:

```json
{ "name": "Аня", "subject": "английский" }
```

Тексты полностью переписываются в `students.json` → `templates`. Доступны
`{name}`, `{when}`, `{time}`, `{date}`, `{lead}`, `{subject}`, `{location}`.

В чате ученику доступны три команды: `/next` — ближайшие занятия, `/stop` —
выключить напоминания, `/start` — включить обратно. Если кто-то отключился, вам
придёт уведомление (при заполненном `TEACHER_CHAT_ID`).

---

## Как урок находит своего ученика

По словам в названии, описании, месте события и в списке участников. По
умолчанию ищется имя из `students.json`, регистр и «ё» не важны — то есть «Аня»
находит и «Английский — Аня», и «урок с Аней».

Если имя в календаре пишется иначе (или наоборот, слишком часто встречается),
задайте свои слова:

```json
{ "name": "Аня", "match": ["Аня", "Анна Петрова"] }
```

Строка вида `"/аня|анна/"` считается регулярным выражением. Ещё можно ограничить
ученика одним календарём: `"calendars": ["Уроки"]`.

Проверить, что кто на что попал, — не отправляя ничего:

```bash
node reminders/bot.js next 7
```

Эта команда показывает каждый урок, кому он засчитан и когда уйдут напоминания;
отдельно называет уроки, не доставшиеся никому, и учеников без уроков. Это самый
быстрый способ поймать опечатку в `match`.

## Команды

| | |
|---|---|
| `npm run reminders` | запустить и оставить работать |
| `node reminders/bot.js --once` | одна проверка и выход — для cron |
| `node reminders/bot.js --dry-run` | показать, что ушло бы, и ничего не отправлять |
| `node reminders/bot.js next [дней]` | расписание и время всех напоминаний |
| `node reminders/bot.js link [Имя]` | ссылка-приглашение |
| `node reminders/bot.js students` | кто подключён |
| `node reminders/bot.js calendars` | какие календари видны в iCloud |
| `node reminders/bot.js test Имя` | отправить пробное напоминание |

## Чтобы работало само

Программа напоминает только пока запущена, а **спящий ноутбук ничего не
отправляет**. Если уроки бывают утром, держите её на машине, которая не
засыпает, — или хотя бы открывайте ноутбук заранее: пропущенное за час
напоминание всё равно уйдёт (см. ниже).

**macOS, чтобы запускалась при входе.** Положите в
`~/Library/LaunchAgents/ru.lessons.reminders.plist`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN"
  "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>Label</key>            <string>ru.lessons.reminders</string>
  <key>ProgramArguments</key>
  <array>
    <string>/usr/local/bin/node</string>
    <string>/Users/ВЫ/Diary/reminders/bot.js</string>
  </array>
  <key>WorkingDirectory</key> <string>/Users/ВЫ/Diary</string>
  <key>RunAtLoad</key>        <true/>
  <key>KeepAlive</key>        <true/>
  <key>StandardOutPath</key>  <string>/Users/ВЫ/Diary/reminders.log</string>
  <key>StandardErrorPath</key><string>/Users/ВЫ/Diary/reminders.log</string>
</dict>
</plist>
```

```bash
launchctl load -w ~/Library/LaunchAgents/ru.lessons.reminders.plist
which node   # подставьте свой путь в ProgramArguments
```

**Linux, systemd:**

```ini
[Unit]
Description=Напоминания об уроках
After=network-online.target

[Service]
WorkingDirectory=/home/вы/Diary
ExecStart=/usr/bin/node reminders/bot.js
Restart=always

[Install]
WantedBy=default.target
```

**Или по расписанию, без постоянного процесса:**

```cron
*/5 * * * * cd /path/to/Diary && /usr/local/bin/node reminders/bot.js --once >> reminders.log 2>&1
```

`--once` тоже разбирает входящие сообщения, так что подключение ученика по
ссылке подхватится на ближайшем запуске.

## Как решается, что отправлять

Всё это живёт в `reminders/schedule.js` и покрыто тестами — самая
неприятная часть здесь не сеть, а время.

- **Каждое напоминание уходит один раз.** Отметки хранятся в
  `reminders/state.json` и переживают перезапуск.
- **Урок перенесли — это новый урок.** Напоминание о новом времени придёт
  заново.
- **Опоздавшее напоминание всё равно уйдёт**, если опоздало не больше чем на
  час (`REMINDERS_GRACE_MINUTES`) — ровно тот случай, когда компьютер спал. Если
  прошло больше, оно молча списывается, чтобы ученик не получил «напоминаю про
  урок» после урока.
- **Урок, добавленный в последний момент**, получит одно напоминание вдогонку —
  но только когда до него уже меньше, чем самая близкая настройка (по умолчанию
  час). Иначе первый же запуск программы разослал бы сообщения всем, у кого урок
  на этой неделе.
- **Про начавшийся урок не пишется ничего.**
- **Отмена и перенос.** Если урок, о котором ученик уже предупреждён, исчез из
  календаря — придёт «урок отменён», а если он нашёлся в другое время — «урок
  перенесён». Осторожно: только после того, как урок отсутствовал в двух
  проверках подряд.
- **Защита от сбоя синхронизации.** Если календарь вдруг прочитался пустым или
  разом пропало больше трёх уроков — ученикам не уходит ничего, а вам приходит
  сообщение, что стоит проверить календарь. Ложное «урок отменён» хуже
  промолчавшей программы.

Отключить сообщения об отменах: `"notifyChanges": false`.

## Настройки

В `.env` (все, кроме первых трёх, необязательны) — см. `.env.example`:

| | |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от @BotFather |
| `APPLE_ID`, `APPLE_APP_PASSWORD` | Apple ID и пароль для программы |
| `APPLE_CALENDARS` | какие календари читать, через запятую |
| `CALENDAR_ICS_URL` | вместо Apple ID — ссылка на опубликованный календарь |
| `CALENDAR_ICS_FILE` | вместо всего — локальный `.ics`, чтобы попробовать |
| `TEACHER_CHAT_ID` | ваш чат: туда уходят сообщения о сбоях (как узнать — ниже) |
| `REMINDERS_EVERY_SECONDS` | как часто перечитывать календарь (300) |
| `REMINDERS_HORIZON_DAYS` | на сколько дней вперёд смотреть (8) |
| `REMINDERS_GRACE_MINUTES` | насколько опоздавшее напоминание ещё отправлять (60) |

В `students.json`: `timezone`, `remind` (за сколько минут напоминать — можно
переопределить у каждого ученика), `notifyChanges`, `includeTitle`,
`includeLocation`, `templates` и сам список.

`students.json` и `state.json` не попадают в git: там имена учеников и их
Telegram.

### Как узнать свой `TEACHER_CHAT_ID`

Необязательная, но полезная настройка: в этот чат бот пишет, если календарь
перестал читаться, если ученик заблокировал бота или отключил напоминания.

Запустите программу, напишите своему боту в Telegram что угодно и посмотрите
в лог — там будет строка вида
`незнакомый чат 424242 (…). Если это вы — впишите в .env: TEACHER_CHAT_ID=424242`.

### Без пароля Apple

Если не хочется заводить пароль для программы, календарь можно опубликовать:
в приложении «Календарь» правой кнопкой по календарю → «Общий доступ» →
«Открытый календарь». Полученную ссылку `webcal://…` впишите в
`CALENDAR_ICS_URL` и оставьте `APPLE_ID` пустым. Но учтите: Apple обновляет
опубликованную копию с задержкой, поэтому только что перенесённый урок программа
увидит не сразу. Для боевого расписания лучше CalDAV.

## Если что-то не так

**«iCloud не принял логин».** Нужен именно пароль для программы с
appleid.apple.com, обычный пароль от Apple ID CalDAV не принимает.

**«В iCloud нет календаря: …».** Название в `APPLE_CALENDARS` должно совпадать
с тем, что показывает `node reminders/bot.js calendars`, буква в букву.

**Ученику ничего не приходит.** Посмотрите `node reminders/bot.js next 7`: если
рядом с уроком «— никто из списка», дело в `match`; если «не подключён» — он не
открыл ссылку.

**«бот уже запущен где-то ещё».** Telegram разрешает опрашивать чат только
одному процессу. Закройте вторую копию — рассылку это не ломает, но команды в
чате будет обрабатывать только первая.

**Часовые пояса.** `timezone` в `students.json` — это ваш пояс, в нём считается
«сегодня» и «завтра». Время самого урока берётся из календаря вместе с его
поясом, так что урок, назначенный в поездке, останется на своём месте.

## Тесты

```bash
npm test
```

Покрыты разбор календаря (повторяющиеся уроки, переносы отдельных занятий,
отмены, `EXDATE`, `UNTIL`, «последняя пятница месяца», переход на летнее время,
события без пояса) и вся логика решений об отправке — включая спавший компьютер,
урок, добавленный за двадцать минут, и пустой ответ календаря.

**Чего не проверяли вживую:** обращения к настоящему iCloud и настоящему
Telegram — писалось без учётных данных под рукой. Формат запросов CalDAV сверялся
со спецификацией, а весь путь отправки прогонялся на локальной заглушке Bot API.
Это то, за чем стоит присмотреть при первом запуске: начните с
`node reminders/bot.js calendars` и `node reminders/bot.js next` — они читают
календарь, но ничего никому не отправляют.
