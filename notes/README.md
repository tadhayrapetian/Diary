# Быстрые заметки

Открыл, написал, закрыл. Ничего не нужно нажимать, чтобы сохранить, и нечего
терять, если браузер закроется на полуслове.

```bash
npm run notes
```

Открыть адрес, который он напечатает (по умолчанию `http://localhost:4244`).
Ключей, аккаунтов и сети наружу не требуется — всё живёт на вашей машине.

---

## Как пользоваться

- **Пишите в верхнее поле.** <kbd>Enter</kbd> — сохранить, <kbd>Shift</kbd>+<kbd>Enter</kbd> — перенос строки.
- **Любая заметка правится на месте.** Просто щёлкните в неё и печатайте:
  сохранение начнётся через полсекунды после того, как вы остановитесь.
- **Стереть весь текст заметки** — значит удалить её (с возможностью вернуть).
- **📌 закрепляет** заметку наверху списка, не меняя время правки.
- **Поиск** фильтрует по мере ввода.
- **Выгрузка** внизу страницы: `.md` — читаемый файл, `.json` — точная копия.

Горячие клавиши:

| | |
|---|---|
| <kbd>/</kbd> или <kbd>Ctrl</kbd>/<kbd>⌘</kbd>+<kbd>K</kbd> | поиск |
| <kbd>n</kbd> | новая заметка |
| <kbd>Esc</kbd> | выйти из поля / сбросить поиск |
| <kbd>Ctrl</kbd>/<kbd>⌘</kbd>+<kbd>S</kbd> | записать всё немедленно |
| <kbd>Ctrl</kbd>/<kbd>⌘</kbd>+<kbd>Z</kbd> | вернуть только что удалённую |

На телефоне страница работает так же; в Safari «Поделиться → На экран
«Домой»» откроет её без адресной строки.

## Про сохранение

Это единственное, что программа обязана делать безупречно, поэтому оно
устроено в три слоя:

```
клавиша ──► память страницы ──► localStorage ──► файл на диске
             мгновенно          мгновенно        через 0,6 с покоя
```

- **localStorage** держит всё, что сервер ещё не подтвердил. Перезагрузка,
  упавшая вкладка или остановленный сервер не съедят набранное: при следующем
  открытии страница дописывает несохранённое сама.
- **Файл** пишется атомарно — сначала во временный файл, затем переименованием
  поверх настоящего. Выключенное на середине записи питание оставит предыдущую
  версию целой, а не половину новой.
- **Ответ приходит только после записи на диск**, поэтому «Всё сохранено» в
  углу — это не обещание, а факт.
- Если сервер молчит, заметка не пропадает: точка в углу краснеет, а попытки
  повторяются с нарастающей паузой, пока он не ответит. Текст новой заметки в
  таком случае возвращается в поле ввода, а не исчезает.

Заметки лежат в `notes/data/notes.json` — обычный JSON, читаемый глазами и
переносимый копированием. Путь меняется в `.env`:

```
NOTES_FILE=~/Dropbox/notes.json
NOTES_PORT=4244
NOTES_HOST=0.0.0.0
```

## Файлы

| | |
|---|---|
| `notes/store.js` | Заметки в памяти и атомарная запись файла |
| `notes/server.js` | Статика и API |
| `notes/export.js` | Выгрузка в Markdown |
| `notes/public/app.js` | Страница: ввод, автосохранение, повторы, поиск |
| `notes/public/styles.css` | Оформление, светлое и тёмное |

API, если захочется дописать своё: `GET /api/notes`,
`POST /api/notes`, `PATCH /api/notes/:id`, `DELETE /api/notes/:id`,
`GET /api/export.md`, `GET /api/export.json`.

`POST` принимает `id` и `created` — так возвращается удалённая заметка, ровно
на своё место.

## Тесты

```bash
npm test
```

`notes/store.test.js` проверяет то, что нельзя проверить глазами: что запись
атомарна и не оставляет мусора, что очередь записей схлопывается и на диск
попадает последнее состояние, что нечитаемый файл откладывается в сторону, а не
затирается, что мусор внутри читаемого файла отбрасывается поштучно, и что
удалённая заметка возвращается с прежним `id` и временем создания.

Страница проверена в браузере отдельно: создание, правка с автосохранением,
закрепление, поиск, удаление с возвратом, восстановление черновика после
перезагрузки и поведение при выключенном сервере — включая то, что правка,
сделанная при недоступном сервере, доезжает до диска после перезагрузки
страницы.
